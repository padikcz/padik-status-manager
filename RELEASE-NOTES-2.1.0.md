# Padik Status Manager 2.1.0

## Novinky

- vlastní Elementor widget `Padik Status List`,
- výběr uloženého seznamu,
- úprava vzhledu přímo v Elementoru,
- vlastní seznamy monitorů z Uptime Kuma,
- WordPress REST proxy bez CORS,
- opravy načítání a editace seznamů.

## Instalace

Stáhněte soubor:

```text
padik-status-manager-2.1.0.zip
```

Ve WordPressu otevřete:

```text
Pluginy → Instalace pluginů → Nahrát plugin
```

Potom plugin aktivujte a nastavte v:

```text
Nastavení → Padik Status Manager
```
